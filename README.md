# XREAL Beam — Windows ADB Tool

Консольный набор инструментов для XREAL Beam: посмотреть состояние устройства, сохранить настройки, установить APK и применить собственные ADB-команды.

**Windows · PowerShell 5.1 · USB/ADB**

[Скачать исходники](https://github.com/jeronimo701/beam-windows-tool/archive/refs/heads/main.zip) · [Полная инструкция](README.txt) · [Технические подробности](DETAILS.ru.md) · [Проблемы](https://github.com/jeronimo701/beam-windows-tool/issues)

## Что можно сделать

- Проверить подключение и состояние батареи.
- Сохранить настройки и списки пакетов в локальный backup.
- Экспортировать снимок настроек.
- Применить проверенный TXT с командами или установить свои APK.
- Восстановить сохранённые ключи и перезагрузить устройство.

Это консольный инструмент, отдельного графического окна у него нет. Начальные пункты меню:

```text
1. Check device
2. Backup only
3. Export settings snapshot
4. Apply commands from txt
...
13. Status
0. Exit
```

## Первый запуск

1. Скачай проект и распакуй его в отдельную папку.
2. Скачай [официальные Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools).
3. Положи рядом с `beam-tool.ps1` файлы `adb.exe`, `fastboot.exe`, `AdbWinApi.dll`, `AdbWinUsbApi.dll`.
4. Подключи **один** Beam по USB, включи USB debugging и подтверди доступ компьютера на устройстве.
5. Запусти `run.bat`, сначала выбери проверку устройства, затем backup.

Если запуск блокируется политикой организации, обратись к администратору. Не отключай защиту ради инструмента.

## Перед изменением устройства

**Backup — не образ устройства и не копия личных файлов.** Он не гарантирует полный откат.

Экспериментальные пресеты `beam-app`, `beam-settings` и `extra_optim` могут конфликтовать и отключать важные компоненты. Рост скорости или автономности не подтверждён. Не выбирай «полный прогон» вслепую.

**Пункт 12 стирает userdata/cache через fastboot.** Это удаление данных, не диагностическая проверка. Инструмент не всегда последовательно проверяет коды ошибок внешних команд; смотри фактический вывод.
