# XREAL Beam Windows ADB Tool

Переносимый консольный инструмент для Windows и XREAL Beam: резервные снимки
настроек, применение TXT-команд, установка APK, управление пакетами и восстановление.
Основной файл — `beam-tool.ps1`, запуск — `run.bat`.

Это самостоятельная PowerShell-обвязка, не официальный продукт XREAL или Google.
Версия в исходном проекте не задана; данная публикация не объявляет новый стабильный релиз.

## Важно перед запуском

- Сначала изучите [полную инструкцию](README.txt) и сделайте независимую копию важных данных.
- Backup здесь — текстовый снимок настроек и списков пакетов, **не образ устройства и не копия личных файлов**.
- `beam-app` отключает системные компоненты, включая keychain и captive portal. Это может нарушить работу устройства.
- `beam-settings` и `extra_optim` — экспериментальные, частично конфликтующие наборы. Наличие ключа в Android settings не доказывает, что прошивка его использует. Улучшение производительности, охлаждения или автономности не подтверждено.
- Пункт 12 запускает fastboot erase userdata/cache и уничтожает данные. Не запускайте его для проверки работы программы.
- Коды ошибок внешних ADB/Fastboot-команд не проверяются последовательно. Сообщение об окончании операции или созданный каталог backup не гарантируют, что все команды выполнены успешно. Проверяйте вывод и файлы вручную.
- Список разрешённых команд TXT — не защитная песочница. Запускайте только собственные проверенные файлы: shell-команды могут менять устройство.
- Restore повторно записывает сохранённые ключи, но не удаляет все добавленные позже ключи и не возвращает файлы/данные приложений. Это не гарантированный полный откат.

## Подготовка и запуск

1. Скачайте проект через Git или Download ZIP на GitHub.
2. Отдельно скачайте Windows SDK Platform-Tools с [официальной страницы Android](https://developer.android.com/tools/releases/platform-tools).
3. Скопируйте `adb.exe`, `fastboot.exe`, `AdbWinApi.dll`, `AdbWinUsbApi.dll` рядом с `beam-tool.ps1`. Файлы Google в Git не включены; сохраняйте лицензионные уведомления из скачанного пакета.
4. Подключите только один XREAL Beam по USB, включите USB debugging и подтвердите доступ компьютера на устройстве. При необходимости установите подходящий USB-драйвер.
5. Запустите `run.bat` в Windows PowerShell 5.1. Начните с пункта 1 (проверка устройства), затем 2 (backup). Не выбирайте полный прогон вслепую.

Для установки приложений положите APK в `app/`; инструмент использует `adb install -r -d`.
Не публикуйте чужие APK или приложения с личными данными без права на распространение.

## Возможности и меню

Полное описание каждого пункта, формата TXT, восстановления и конфликтов:
[README.txt](README.txt).

- Проверка подключения, статус и батарея.
- Backup в `backups/` и экспорт в `settings-snapshots/`.
- Пользовательские команды из `commands/` с подтверждением APPLY.
- Отключение пакетов, два альтернативных пресета и установка APK.
- Восстановление с подтверждением RESTORE, перезагрузка и отдельный опасный сброс.

`commands/fresh-beam-*.txt` — перенесённые из исходного проекта примеры
базовых настроек конкретного Beam. Они не являются универсальными заводскими
значениями для любой версии прошивки и меняют настройки, в том числе язык и радио.
`commands/example-settings.txt` отключает три масштаба анимации.

## Проверка

Запуск локальных тестов без подключения устройства:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\test.ps1
```

Тесты загружают только определения функций и таблицы команд через AST.
ADB/Fastboot и пользовательский ввод заменены имитациями: настоящие устройства
не опрашиваются и не изменяются. Проверка физического XREAL Beam, пресетов,
factory reset и восстановления на устройстве при публикации не выполнялась.
Подробности: [VALIDATION.md](VALIDATION.md).
