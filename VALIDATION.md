# Проверка публикации

Дата: 2026-10-21. Версия в предоставленных исходниках не указана.

- PowerShell 5.1: основной скрипт разобран через AST без синтаксических ошибок.
- 22 изолированных теста PASS: разбор аргументов, маршрутизация команд, отбрасывание неподдерживаемых команд, обработка отсутствующего/неавторизованного/одного/нескольких устройств, отмена RESET, таблицы пресетов и все командные TXT.
- ADB/Fastboot в тестах заменены функциями-имитациями. Интерактивный основной цикл не запускался. Реальные устройства не опрашивались; reset, перезагрузка, применение пресетов, установка APK и восстановление на устройстве не выполнялись.
- SHA256 `beam-tool.ps1`: `04669f0ebbdd70cb368ad6957629e02de3447ea210498c969fd5a1bce1e3ecd9`. Совпадает с исходной папкой: функциональный код не менялся.
- Gitleaks 8.30.1: сканирование подготовленной папки без находок. Проверка правилами сканера не гарантирует отсутствие всех возможных секретов.
- Исходные ADB/Fastboot 35.0.2-12147458 и две DLL имеют Valid Authenticode Google LLC. Проверялись только версии и подписи, не взаимодействие с устройством. Эти бинарники в Git не включены.
- Оригинальная папка не изменялась. Пользовательские APK, логи, backups и снимки устройства отсутствуют в публикуемом наборе.

## Ограничения

Не подтверждены эффективность пресетов и совместимость с конкретной прошивкой Beam. Множество ключей могут не использоваться прошивкой. Сбой внешних команд не везде приводит к остановке; backup не является полноценным образом или гарантией успешного отката. Разрешённые TXT-команды не являются песочницей. Подробные предупреждения размещены в README.

Это публикация исходников без присвоения новой версии и без отдельного GitHub Release/CI. Самостоятельная лицензия на авторский код не назначалась.
